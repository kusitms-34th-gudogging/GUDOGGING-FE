# 지침 문서 작성 규칙

`AGENTS.md`·`CLAUDE.md`·`.claude/**`를 고칠 때

## 어디에 쓸까

- 매 대화마다 필요 → `AGENTS.md` (진입점만, 짧게)
- 특정 경로 작업마다 필요 → `.claude/rules/*.md` + frontmatter `paths` (그 경로 작업 때만 자동 로드)
- 특정 경우에만 필요 → `.claude/docs/{주제}/*.md` + 해당 규칙의 `이럴 때 더 읽기`에 한 줄
- 순서가 있는 작업 → `.claude/skills/{이름}/SKILL.md` + `AGENTS.md` "작업별 시작 문서"

규칙 파일이 커지면 매번 로드되는 양이 늘어남 → 가끔만 필요한 섹션은 `docs/`로 빼고 `이럴 때 더 읽기`로 연결

## 쓰는 법

- 규칙 하나는 **한 파일에만**. 다른 곳엔 경로만 적음 (설명 복사 금지)
- 경로는 저장소 루트 기준 전체 경로로 (`` `.claude/rules/unit-test.md` ``). 파일 이름만 쓰면 검사 실패
- lint·prettier가 강제하는 건 쓰지 않음 (설정 파일이 원본)
- 다른 문서는 맨 아래 `## 이럴 때 더 읽기`에 "~할 때 → 경로" 형식으로만 연결. 조건은 작업자가 바로 판단할 수 있게 구체적으로
- 조건 없이 "항상 읽어라"는 연결 금지 (따라가다 전부 읽게 됨). 정말 매번 필요하면 그 내용을 이 파일에 둠. 예외: 진입용 포인터 파일은 `항상 읽기:` 한 줄 (`.claude/rules/tokens.md`)
- 상위 문서로 돌아가는 링크 금지 (상위 문서를 읽고 들어온 상태)
- 문서가 아닌 참고용 소스는 `참고 코드:` 줄 (읽기 강제 아님)
- 문서를 옮기거나 이름을 바꾸면 그 경로를 적은 곳도 같이 고침

## 검사: 지침 문서를 커밋하면 자동 실행 (lint-staged). 직접 실행은 `pnpm docs:check`

- 적힌 `.md` 경로가 실제로 있는지
- 규칙에 `paths`가 있는지
- `docs`·스킬이 다른 문서 어딘가에서 안내되는지 (아무도 안 가리키는 문서 금지)
