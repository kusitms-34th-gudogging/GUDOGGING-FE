# 커밋 메시지 컨벤션

```
#이슈번호 [타입] 작업내용
```

- 예: `#7 [FEAT] 로그인 페이지 구현`
- 이슈 번호가 없는 브랜치면 생략: `[CHORE] 안쓰는 파일 정리`
- 작업내용은 한국어, 명사형으로 끝냄 (`~ 구현`, `~ 추가`, `~ 수정`)
- `.husky/commit-msg`가 `^(#[0-9]+ )?\[[A-Z]+\] .+` 로 검사

## 타입 (이슈 템플릿 기준)

| 타입     | 용도                     |
| -------- | ------------------------ |
| FEAT     | 새 기능                  |
| FIX      | 코드 수정, 버그 수정     |
| REFACTOR | 동작 변화 없는 구조 개선 |
| DOCS     | 문서                     |
| CHORE    | 설정·빌드·기타           |
| SETTING  | 프로젝트 초기 세팅       |
